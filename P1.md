# P1.md — phase one: the vertical slice

**Goal:** the atom in your hands, on your actual phone. The shell renders
`getView` and sends taps back through `act`; the journal is always visible;
the run survives being closed; and the path off the shore leads somewhere.

P0 proved the engine. P1 proves the engine is *enough* — that a shell can be
built against `GameAPI` and nothing else.

## what is frozen

Everything P0 froze, unchanged: **VOCAB.md**, the **GameAPI**, and
`.llm/rules/`. P1 adds one more:

- **The shell touches `GameAPI` only.** `newRun`, `act`, `getView`, and
  `serialize`/`parse`. It does not import `resolve.ts`, does not read
  `bundle.scenes` to decide what to draw, and does not keep game state of its
  own. If the shell needs something the API cannot give it, that is a finding
  against the API, not a reason to reach past it.

The shell is disposable. The contract it consumes is not.

## no framework

The shell is vanilla TypeScript over the DOM, bundled by Vite.

A narrator line and a list of tappable objects is not a state-management
problem. `.llm/rules/no-dead-scaffolding.mdc` forbids a dependency that saves
eight lines, and a UI framework here would save none — `getView` already
returns exactly what to draw, and every tap is a full redraw of a page with
one paragraph and five buttons.

Vite is not scaffolding: Capacitor wraps built web assets, so something must
build them. It also lets `scripts/` finally import `src/core` instead of
copying it (P106).

## what P106 is repaying

P0 shipped two hand-copied engines. `scripts/build-content.mjs` carries a
second copy of `parseScene`'s vocabulary gate and `scripts/play.mjs` carries a
second copy of `resolve`. Both headers say why: a `.mjs` script under Node 20
cannot import a `.ts` module without a loader the repo did not have.

They have **already diverged** — `play.mjs` drops the `say` effect on a
refusing branch, where `resolve.ts` emits it. No symptom yet, because every
refusal in `shore.yaml` carries `refuse` alone. The first author who follows
VOCAB.md's own example loses their prose silently.

P106 deletes both copies. This is the debt P0 knowingly took on, and it is
paid in the first wave that can afford it.

## exit gate

- `npm run law` green on main.
- `npm run progress` shows all twenty-one cards green.
- `npm run build` produces web assets; `npx cap sync android` is clean.
- You have personally, **on your phone**: read the book and been refused,
  studied the stone, read it again and watched the journal gain the
  procession, walked up the path, and closed the app and reopened it to find
  the run where you left it.

That last line is the phase. The rest is how it gets there.
