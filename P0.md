# P0.md — phase zero: the atom, autonomously

**Goal:** the basic loop — *present → tap (free) → act → delta → present* —
running headless, built entirely by agents from the cards in `tasks/`,
proven by a root acceptance that encodes the affordance rule: **the book
refuses, then the book opens.**

No UI this phase. The deliverable is an engine you can play in a
terminal.

## what is frozen (ratify before dispatch)

- **VOCAB.md** — the closed gate/delta word set.
- **GameAPI** (specified in card H001): `newRun(seed, bundle)`,
  `act(state, ref, input?) → {state, effects}`, `getView(state)`.
  The shell (P1) will consume only this.
- **`.llm/rules/`** — the engineering law CI enforces.

These three are the expensive-to-change trio. Everything else is
disposable.

## dispatching

From a fresh clone, per READY card (see `npm run board`):

```bash
git checkout -b factory/H003
claude -p "Work exactly one card: tasks/H003-card-schema.yaml. Follow AGENTS.md to the letter." \
  --max-turns 60
npm run law && npx vitest run tests/acceptance/H003.schema.test.ts
```

Or dispatch each READY card as an atelier job with the same one-line
prompt. PRs merge in any order within a wave — scopes are disjoint by
task-lint's guarantee.

## exit gate

- `npm run law` green on main (typecheck, lint, unit tests, task-lint,
  content-lint once H005 lands).
- `npm run progress` shows all nine cards green.
- You have personally, in `npm run play`: tapped the book and been
  refused, studied the stone, read the book, and seen the journal gain
  the procession. The atom, in your hands.
